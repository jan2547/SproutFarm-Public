🌱 SproutFarm

A cozy 2D pixel-art farming game built with Godot 4 and GDScript.

🎮 About the Game

SproutFarm is a work-in-progress farming simulation set on a peaceful island surrounded by a lake.

Players can explore the island, cross wooden bridges, and eventually grow crops, decorate their farm, and care for animals.

✨ Features

* Player movement using WASD
* Four-directional character animations
* Camera that follows the player
* Custom-designed island map
* Basic collision system

🚧 Planned Features

* Planting, watering, and harvesting crops
* Inventory and farming tools
* Autonomous farm animals
* Day and night cycle
* More areas to explore

🛠️ Built With

* Godot 4
* GDScript
* Git and GitHub
